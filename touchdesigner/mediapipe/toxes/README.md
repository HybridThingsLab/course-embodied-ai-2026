# MediaPipe's .tox files go here

Download `release.zip` from
[MediaPipe for TouchDesigner](https://github.com/torinmb/mediapipe-touchdesigner/releases),
unpack it and copy all the `.tox` files of its `toxes` folder into this folder:
`MediaPipe.tox` and its helpers, all from the same release. `03_sense.toe` and
`05_compose.toe` load `MediaPipe.tox` from here. See
[Camera tracking with MediaPipe](../../../docs/3-sense.md#camera-tracking-with-mediapipe).
