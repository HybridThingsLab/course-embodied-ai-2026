# Getting Updates from GitHub with GitHub Desktop

*A beginner-friendly handout for design students · macOS and Windows*

Your course materials or project files are stored in a **GitHub repository**—an online folder that keeps track of changes. With **GitHub Desktop**, you can download those files and get updates from your instructor without using the terminal.

> **In this course, you only need to download updates.** You do not need to learn how to commit or push yet.

## 1. Install GitHub Desktop

1. Download **[GitHub Desktop](https://desktop.github.com/)**.
2. Install and open the application.
3. Follow the initial setup instructions. Sign in to GitHub if prompted.

## 2. Download the repository (only once)

This is called **cloning**. It creates a copy of the online repository on your computer.

1. Open **GitHub Desktop**.
2. Choose **Clone a Repository from the Internet...**.
3. Select the **URL** tab and paste the repository URL, which in our case is "https://github.com/HybridThingsLab/course-embodied-ai-2026.git".
4. Choose a **Local Path** (the folder where you want to save the files).
5. Click **Clone**.

Your project files are now on your computer. **You only need to clone the repository once.**

## 3. Get the latest updates

Do this whenever your instructor announces new or updated files:

1. Open **GitHub Desktop**.
2. Check that the correct project is selected under **Current Repository**.
3. Click **Fetch origin** at the top. This checks whether updates are available.
4. If GitHub Desktop finds updates, click **Pull origin** to download them.

Your local project folder now contains the latest files. If no updates are available, you're already up to date.

## 4. Find and open your files

In GitHub Desktop, choose **Repository → Show in Finder** (macOS) or **Repository → Show in Explorer** (Windows).

Open the files using the applications you normally use for your design work.

## Important: Avoid editing the original course files

- **Pull** downloads updates from GitHub to your computer.
- You **do not need to Commit or Push** for this course workflow.
- If you want to experiment with a project, **copy the file and rename the copy, in the same folder**, before editing it.
- Editing files inside the cloned repository can interfere with future updates.
- If GitHub Desktop warns about **local changes**, a **conflict**, or files that would be overwritten, **do not discard your changes**. Ask us or your fellow students for help.

## Three words to remember

| Term | Meaning |
| --- | --- |
| **Clone** | Download the repository for the first time. |
| **Fetch** | Check whether new updates are available. |
| **Pull** | Download the updates into your existing project folder. |

### Your routine for every class

**Open GitHub Desktop → Fetch origin → Pull origin (if available) → Open your files**
